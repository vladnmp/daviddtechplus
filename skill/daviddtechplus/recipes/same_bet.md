# Same-bet check

Which symbols on the member's list moved almost as one, and how many independent bets the list moved like, lately vs usually.

1. One scan of the list (1 unit, 2-10 symbols); its same-bet check follows the table.
2. The pairs that moved almost as one or as mirror images (correlations of daily returns lately and usually) and how many independent bets the list moved like.
3. How strongly the list moved together lately vs usually, and on the group's worst days next to the reading from the usual link alone.
4. An offer to repeat it weekly with the scheduled tasks of the member's own app, or with other symbols swapped in.
